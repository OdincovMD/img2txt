# Исследовательский лог: img2txt

Этот документ теперь служит индексом исследовательских материалов по пайплайну `img2txt`.

**Дата последнего обновления:** 2026-04-19

## Структура по шагам

1. [Шаг 1. Извлечение признаков](./research_step1_extraction.md)
2. [Шаг 2. Бакетизация признаков](./research_step2_bucketing.md)
3. [Шаг 3. Ранжирование важных признаков](./research_step3_ranking.md)
4. [Шаг 4. Генерация клинического описания](./research_step4_generation.md)

## Что внутри

Вынесены именно:

- исследовательские гипотезы;
- эксперименты;
- наблюдения;
- промежуточные и текущие выводы.

Не включены:

- рефакторинг;
- техническая чистка кода;
- организационные изменения без исследовательского результата.

## Краткий итог

- Шаги 1 и 2 дают сильное табличное представление.
- Основной исследовательский bottleneck проекта находится на Шаге 3.
- Лучшее практическое направление на текущий момент — табличный `XGBoost`.
- Следующий главный эксперимент — `xgb_classifier_chain`.
- Шаг 4 уже достаточно стабилен и в первую очередь зависит от качества top-k признаков со Шага 3.

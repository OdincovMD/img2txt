# Шаг 4. Генерация клинического описания

**Основные файлы:** [generation/description_inference.py](../generation/description_inference.py), [generation/description_templates.py](../generation/description_templates.py), [generation/classification_types.py](../generation/classification_types.py)

## Постановка

На вход поступают:

- `important_labels` из Шага 3;
- опционально структурная классификация образования.

На выходе нужен связный клинический текст на русском языке:

- без постановки диагноза;
- без рекомендаций;
- только наблюдательное описание.

## Что пробовали

### 1. Генерация из top-k признаков

Базовая идея Шага 4:

- брать top-k важных признаков;
- раскрывать их в человекочитаемые формулировки;
- подавать это в instruction model;
- получать 3-5 предложений клинического описания.

### 2. Структурированный prompt

Вместо свободного перечисления был выбран более строгий шаблон:

- форма и размер;
- границы;
- цветовой паттерн;
- текстура.

Это нужно, чтобы текст был:

- стабильнее;
- клинически чище;
- менее склонен к галлюцинациям.

### 3. Few-shot prompting

Для генерации были добавлены few-shot примеры:

- один более спокойный случай;
- один более подозрительный по структуре и цветовому паттерну.

Идея состояла в том, чтобы стабилизировать стиль и удерживать модель в режиме наблюдательного описания.

### 4. Классификация как дополнительный контекст

Отдельная гипотеза:

> если помимо top-k признаков дать структурную классификацию, описание может стать более связным.

Этот канал сделан опциональным и должен использоваться именно как контекст описания, а не как источник диагноза.

## Текущее состояние шага

Шаг 4 концептуально стабилен:

- генерация идет из top-k признаков;
- prompt жестко ограничивает стиль;
- диагноз и рекомендации запрещены;
- классификация используется только как дополнительный контекст.

Главный bottleneck сейчас не в генеративной модели как таковой, а в качестве top-k признаков, приходящих с Шага 3.

## Вывод по шагу

Качество генерации зависит прежде всего от качества ранжирования важных признаков. Если Шаг 3 ошибается, Шаг 4 может написать хороший по форме текст, но по неправильным основаниям.

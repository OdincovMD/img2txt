# Шаг 1. Извлечение признаков

**Основные файлы:** [extraction/feature_extraction_batch.py](../extraction/feature_extraction_batch.py), [extraction/segmentation.py](../extraction/segmentation.py), [extraction/feature_schema.py](../extraction/feature_schema.py)

## Роль шага

На этом шаге из изображения и маски очага строится плоский набор численных признаков, который затем используется:

- для бакетизации;
- для табличных моделей Шага 3;
- косвенно для финального текстового описания.

## Что извлекается

Из изображения и сегментации строятся:

- цветовые признаки;
- локальные цветовые градиенты;
- геометрия формы;
- характеристики границы;
- текстурные признаки.

Именно этот слой стал базой для дальнейшего поворота проекта в сторону tabular-first подхода.

## Что было важно исследовательски

### 1. Маска полезна для extraction, но не обязательно для ranking

Сегментационная маска нужна, чтобы корректно извлекать признаки очага, но последующие эксперименты на Шаге 3 показали, что:

- передача маски напрямую в нейросетевую модель ранжирования
- не дает заметного прироста качества

по сравнению с использованием уже извлеченных табличных признаков.

### 2. Сырые признаки оказались сильнее, чем ожидалось

Ожидание в начале было таким:

- изображение является главным источником сигнала;
- численные признаки скорее вспомогательны.

Фактически оказалось наоборот:

- извлеченные табличные признаки несут большую часть полезной информации для выбора важных признаков;
- именно это наблюдение позже привело к переходу от CNN-first к tabular-first логике на Шаге 3.

## Вывод по шагу

Шаг 1 дает достаточно сильное и информативное табличное представление очага. Для задачи ранжирования клинически важных признаков это представление оказалось главным носителем сигнала.
